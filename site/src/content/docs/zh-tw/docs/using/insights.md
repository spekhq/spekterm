**對話計量** 呈現你怎麼跟 Claude Code 工作：什麼時候在工作、一次待多久、怎麼跟 agent 說話、讓它做些什麼。它分成兩個分頁：

- **數字**：從你的對話算出來的圖表。打開它不花任何錢，也不會把任何東西送出去。
- **讀後感**：一份文字的解讀，寫你怎麼跟 agent 說話。只在你要求時由你自己的 `claude` 產生，並連同日期保存下來。

在活動列（最左邊那一欄）按 **對話計量** 打開它。它會蓋住整個視窗；按 `Esc` 或 **✕ Esc** 關閉，焦點會回到活動列。開著的時候，spekterm 其他的快捷鍵會暫停，跟其他對話框一樣。

## 數字從哪裡來

Claude Code 會把每一段對話的紀錄寫在 `~/.claude/projects` 底下，預設 30 天後刪除。spekterm 讀這些紀錄，把它要計算的部分另存一份在自己的資料夾裡，所以 Claude Code 已經刪掉的那幾個月，數字裡也還在。

- 紀錄會在 spekterm 啟動後讀一次，之後每次打開對話計量時再讀一次。讀的期間畫面會顯示 **正在掃描 transcript…**。
- 它涵蓋 Claude Code 留有紀錄的**每一個專案**，不只 rail 上的資料夾，也不只選中的那一個。在 spekterm 之外開的 session 也算在內。
- 如果你把 Claude Code 的資料放在別的地方，請在 shell 裡設定 `CLAUDE_CONFIG_DIR`，然後重開 spekterm。找不到任何紀錄時，畫面會說找不到來源，而不是顯示一片空白的圖表；來源存在但裡面還沒有東西時，也會直接這樣說。
- 「你的訊息」指的是你自己打的字。Claude Code 或工具代你加進對話的文字不算在內，**不計為我的紀錄** 會說明這部分佔了多少。
- spekterm 為了產生讀後感（見下文）而執行的 session，一律不計入。

## 數字

在頂端選擇時間範圍：**全部時間**，或最近 7、30、90 天。每一張圖都跟著它。

圖表分成四組：

- **節奏**：**一週的節奏**（你在每個星期幾、每個小時送出的訊息數，以你的時區呈現）與 **我一次坐多久**（一段一段的工作時間，中間有一陣子沒動靜就切開）。
- **習慣**：**我一次講多長**（每則訊息的字數）、**每次對話幾個回合**，以及 **我什麼時候踩煞車**（你每天打斷 agent 幾次）。
- **我在做什麼**：**哪個專案吃掉我的字**、**Bash 實際在跑什麼**（每個指令的第一個字，含 subagent 跑的）與 **我真正在用的 skill**（含 subagent 類型）。
- **我怎麼說話**：**字面線索**（以問句結尾、以祈使句開頭、含有更正／保留／客套的字眼、只有一句回應的訊息各佔多少）、**中文與英文**，以及 **我最常說的話**。

分布一律呈現中位數、p75 與 p90，不用平均數：少數幾段特別長的 session，就會把平均數拉得離常態很遠。每張圖都在 **來源** 標出它是從紀錄的哪個部分算出來的。**字面線索** 會列出每一類的判定規則與幾則真實的訊息，讓你判斷它算的是不是你以為的那個東西；它比對的是字面，不是語氣。

你自己的字只會出現在兩個地方：你送過至少三次的短訊息（**我最常說的話**），以及 **字面線索** 底下的短例句。沒有任何畫面會列出你所有的訊息。

## 讀後感

**產生一份讀後感** 會請你自己的 `claude` 讀你在「數字」分頁選定範圍內打的訊息，寫下它注意到你怎麼跟 agent 說話。它不會自己執行：不會在啟動時跑，也不會在你打開分頁時跑。

送出任何東西之前，spekterm 會先問 **把這些訊息送給 Anthropic？**，並列出：

- 涵蓋的期間、專案數、訊息數，以及會送出多少字元；
- 要求使用的模型；
- 送出的只有你打的字：沒有工具輸出，也沒有你 repository 裡的檔案內容。

如果範圍內的內容超過一次能處理的量，會從最舊的那一端先捨棄，畫面上的數字就是實際會送出的那一份。在你按下 **送出並產生** 之前，什麼都不會離開你的電腦。

產生一份讀後感要幾分鐘，也會花錢，花了多少會記在讀後感上。

- **它以你的 `claude` 登入身分執行。** 只存在於 shell 環境變數裡的憑證（例如 API key）不會被帶過去。如果你只用這種方式登入，讀後感會失敗，錯誤訊息也會說明這一點。
- 它在 spekterm 自己的一個空資料夾裡執行，不能使用任何工具，因此讀不到你的任何 repository。Claude Code 為這一趟留下的對話紀錄，會在結束時刪除。
- **每一條觀察都附一段引用**，引自你的訊息。spekterm 會拿每段引用去比對你實際打過的字，找不到的那條觀察就丟掉，讀後感上會寫丟了幾條。一條都沒留下時，什麼都不會存。

讀後感並存在 spekterm 的資料夾裡，只有你的使用者帳號讀得到，列在 **已儲存的讀後感** 底下，最新的在最上面。新的不會蓋掉舊的，所以你可以比較它在相隔幾個月時說了什麼。每一份都會寫明產生時間、涵蓋的期間、要求的模型、讀了多少、丟了幾條觀察、花費，以及它自己的對話紀錄有沒有刪掉。如果它涵蓋的期間跟「數字」分頁目前選的範圍不同，也會標出來。

存了什麼、送出了什麼，見[資料與網路](/zh-tw/docs/reference/data-and-network/)。
